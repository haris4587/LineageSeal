# Documentary provenance policy v1
Each release and source must record dataset ID, version and SHA-256 of its CSV artifact.
All upstream datasets must be identified with exact versions and digests.
Transformation evidence must describe grouping, units, timezone, aggregation, filtering and enrichment.
Release, source and transformation documents must agree with each other and the submitted claim.
A missing required fact is a provenance gap; an explicit contradictory version or digest is conflicting lineage.
This policy covers documentary lineage only; it does not certify collection truth, copyright or execution.
